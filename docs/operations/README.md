# 运维与部署文档

维护基线：2026-11-15（对应 `0.3.30` 及修复轮源码）。本目录只写**当前源码真实存在**的机制；未接入或未实现的开关不在文档中承诺。历史章节与日期化验证记录见[进度](../state/progress.md)。

| 文档 | 用途 |
| --- | --- |
| [安装与构建机制](install-and-build.md) | 发布包/源码检出的安装差异、`postinstall` 与首次启动自愈构建、构建时长与超时基线 |
| [环境变量参考](environment.md) | 部署/运维变量与内部调试变量的分诊、默认值与作用 |
| [数据目录、隐私与留存](data-and-privacy.md) | 数据根不止 agent 目录、部署隔离、遥测关闭、删除与恢复副本的实际行为 |
| [发布、降级与回滚](release-and-rollback.md) | npm 升降级、应用内更新失败处理、`.next-releases` 回退、数据备份与恢复 |

通用前提：

- 版本要求以 `package.json` 的 `engines` 为准：**Node.js ≥ 22.19.0**。CI 覆盖 22.19.0、22.22.2 与 24。自动代理需要 Node 24 或 ≥ 22.21，详见 [README 的代理一节](../../README_zh.md#代理)。
- 安装、升级、回滚前先停掉正在运行的 `piweb`（同一安装目录），并备份数据目录；运行中的实例不要直接替换 `.next` 或安装目录。
- 本文中的构建耗时来自 2026-11-15 审计的本机实测（Windows、28 核 / 16 GB、含并发负载），只作为超时设置基线，不是性能保证。
