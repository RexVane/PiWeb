# Pi 扩展、技能与提示词模板

PiWeb 使用 Pi 原生的包管理器与资源加载器。左侧栏提供「技能」「扩展」「提示词模板」三个入口，按个人和项目作用域查看及管理原生资源。

## 安装与管理

使用 `pi install <source>` 安装 npm、Git 或本地包，然后在 PiWeb 中刷新。扩展页只管理已安装的包，支持查看、启停、更新和卸载，不提供安装、设计或开发工作区入口。本地包引用源目录；卸载不会删除源代码。

个人包配置位于 `~/.pi/agent/settings.json`，项目包配置位于工作区的 `.pi/settings.json`。技能和提示词模板继续由 Pi 发现并加载。正在运行的会话会在本轮结束后应用资源变更。

## 扩展交互

Pi 原生选择、确认、输入和编辑请求使用 PiWeb 的内置界面。现有 JSON UI 支持见[扩展网页交互](extension-web-ui.md)。

PiWeb 不再提供推荐扩展目录、独立资源网页视图、资源后台服务、iframe 消息协议或扩展开发工作区。旧包中的 `piweb` 声明不再被读取；普通 Pi 扩展仍通过 Pi 原生机制加载。
