# PiWeb 0.3.36 — changes since 0.3.35

整理于 2026-11-21。基线为 `v0.3.35`；本文描述当前源码，不代表 npm 或 GitHub 已发布此版本。

## 中文

### 扩展与提示词

- 「扩展」页管理已安装的 Pi 包；使用 `pi install <source>` 安装后刷新。
- 不再内置问答工具和自动化入口。需要选择题弹窗时可另装「问用户」；旧版内置自动化不会由新版自动接管。Pi 的普通选择、确认和输入在没有合适扩展时仍用内置界面。
- 保留 Pi 原生扩展、技能和提示词管理；移除自建资源网页桥接、后台服务和开发工作区。
- 新增独立的「提示词模板」页，按个人／项目来源查看、启停和管理 Pi 发现的模板。

### 会话、模型与数据

- 聊天把工具调用按阶段组织：运行中的阶段展开，已完成的阶段可折叠。思考片段按发生顺序穿插，命令显示用途摘要；已查看的图片可折叠预览。上下文压缩与模型切换也会显示在时间线里。
- 自定义模型先尝试从已配置端点和 Pi 目录补齐窗口、输出上限、图片支持和推理支持；仍缺失才提示手填。手工填写和显式覆盖不会被自动结果改写。
- 普通项目的生长树快照留在 PiWeb 的 `web-growth/` 数据目录，不在项目里创建 `.git`。已有 Git 项目仍按 Git 工作区处理；之前已使用独立快照库的项目继续用原库。
- 会话、附件、技能、提示词模板及受支持的已装包移除走系统回收站；回收失败不降级为永久删除。具体范围和恢复步骤见[数据与留存](../operations/data-and-privacy.md)。

### 升级提醒

升级前先停止运行中的实例并备份 agent 目录。依赖旧版内置自动化的用户应先确认替代方案。Pi 运行时依赖仍统一锁定为 **1.5.2**。安装位置及扩展兼容性见[扩展与 Pi 包](../resources.md)，发布与回退操作见[运维文档](../operations/release-and-rollback.md)。

## English

- Manage installed packages from **Extensions**; install packages with `pi install <source>` and refresh.
- Native Pi extensions, skills and prompt templates remain supported. The custom resource views, hosts and development workspace have been removed.
- A dedicated Prompt Templates page manages user and project templates discovered by Pi.
- The chat timeline groups tool activity into collapsible phases, interleaves reasoning chronologically, previews viewed images and shows compaction and model changes.
- Model settings fill missing capabilities from endpoint metadata and the Pi catalog before asking for manual input; explicit settings remain authoritative.
- Plain-workspace snapshots live in PiWeb data rather than a project `.git`. Supported removals use the system Trash, with no silent permanent-delete fallback.

Stop the running instance and back up the agent directory before upgrading. Old built-in automation is not automatically carried over. Pi runtime dependencies remain pinned to **1.5.2**.
