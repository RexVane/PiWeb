# PiWeb 0.3.38

## 中文

- 内置 Pi 运行时包（`@earendil-works/pi-*` 与 Chord）从 **1.5.2** 统一更新到 **1.6.1**。
- 本版由自动化流程生成：依赖更新后已通过完整的类型检查、测试、构建与安装包校验。

升级前先停止运行中的实例并备份 agent 目录，然后执行 `npm install -g @rexvane/piweb@0.3.38`。

## English

- Update the bundled Pi runtime packages (`@earendil-works/pi-*` and Chord) from **1.5.2** to **1.6.1**.
- Generated by the automated update workflow after the full typecheck, test, build and package verification passed.

Stop the running instance and back up the agent directory before upgrading with `npm install -g @rexvane/piweb@0.3.38`.
