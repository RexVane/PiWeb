# PiWeb 0.3.35

## 中文

本版集中修复模型思考档位、会话导入、文件预览与排队编辑，并包含输入性能及进程锁改进。

### 新功能与体验改进

- **排队消息行内编辑**：在待发消息所在行直接修改，✓ 确认、× 取消，不覆盖主输入框草稿。保留图片、消息类型和队列顺序；前面的消息送达不会导致编辑错位，已送达或被修改的消息会拒绝过期编辑并保留编辑草稿。
- **自动思考档位**：按「手动映射 → Pi 官方模型能力 → 后台探测缓存 → SDK 默认值」解析，新增手动档位映射编辑器和自动状态显示。
- **输入性能**：改善删除与光标反馈，隔离输入、草稿和流式渲染更新。
- **大项目与预览**：优化轨迹/文件快照，补充大文件内容省略、磁盘版本和缺失文件查找提示。
- **文档与加载**：更新 README、截图和导入来源说明，修复空闲预加载动态导入的异常处理。
- **设置下拉框**：同一时间只展开一个，随滚动、缩放和窗口变化重新定位，并限制移动端尺寸。

### 修复

- 修复导入会话缺少 assistant usage 时无法继续对话的问题。只对带导入标记的会话做兼容处理，保留分支、消息 ID 和有效用量；未知用量记为 0，不伪造账单。
- 会话导入界面隐藏没有会话的来源，重扫后自动处理已消失的选中来源。
- 文件预览区分工作区外路径、文件不存在和目录；恢复标签页时规范化工作区内绝对路径，保留上传文件来源信息。
- 进程锁只登记跟踪树根进程，避免后代 PID 累积和 PID 重用导致旧锁误判存活；显式启动的新跟踪树仍正常登记。
- 隔离测试环境中的生产 HTTP guard，使用 TypeScript 7 CLI 执行完整构建类型检查。

### 隐私与兼容性

- 官方模型能力匹配不产生额外模型请求。未知兼容端点的后台探测使用短合成请求、负向对照与缓存，不发送用户会话，跳过 OAuth、命令式凭据和扩展注册的提供商。
- 不需要后台探测时，设置 `PIWEB_AUTO_THINKING_PROBE=0`。手动思考档位配置始终优先。
- Pi 运行时包继续统一锁定 **1.5.2**；本版不升级 Pi 引擎，不迁移或删除用户会话。

安装：`npm install -g @rexvane/piweb@0.3.35`。升级前请先停止运行中的实例并备份数据，完成安装后再启动。

## English

This release improves queued-message editing, thinking-level configuration, imported-session compatibility, file previews, input responsiveness and process-lock tracking.

- Edit queued messages **inline with confirm/cancel**, without replacing the composer draft or dropping images. Preserve queue type/order and safely reject edits to messages already delivered or changed.
- Resolve thinking capabilities in priority order: **manual map → official Pi model catalog → background probe cache → SDK defaults**. Add a manual mapping editor and automatic resolution status.
- Improve deletion/caret feedback and isolate draft/input updates from streaming rendering.
- Improve large-project snapshots, omitted-content/disk-version notices and missing-file lookup.
- Refresh READMEs, screenshots and import-source documentation; guard idle-prefetch dynamic imports.
- Keep settings dropdowns mutually exclusive and correctly positioned during scrolling, resizing and mobile viewport changes.
- Resume imported sessions whose assistant messages lack usage, without rewriting valid billing data, IDs or branches. Hide empty import sources.
- Distinguish out-of-workspace, missing-file and directory errors; normalize restored workspace tabs while preserving upload sources.
- Track process-tree roots rather than every Node descendant, avoiding stale locks caused by accumulated/reused PIDs.
- Isolate test guard state and retain full production type checking through the TypeScript 7 CLI.

Official catalog matching needs no extra requests. Background probes use short synthetic inputs and caching, never user conversations; OAuth, command credentials and extension providers are skipped. Set `PIWEB_AUTO_THINKING_PROBE=0` to disable background probing.

Pi runtime packages remain pinned to **1.5.2**. No user-session migration or deletion is required. Stop the running instance and back up data before upgrading with `npm install -g @rexvane/piweb@0.3.35`.
