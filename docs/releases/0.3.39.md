# PiWeb 0.3.39

## 中文

- 内置 Pi 运行时包（`@earendil-works/pi-*` 与 Chord）从 **1.6.1** 统一更新到 **1.7.0**，并同步默认模型映射与供应商图标。
- 优化冷启动性能：异步化服务启动钩子、延迟更新检查并启用后台预热，加快启动器就绪探测与高频 API 的按需加载速度。
- 统一有效上下文拆解并新增上下文检查弹窗（Context Inspector）。
- 支持外部 `settings.json` 与工作区资源的实时同步。
- 修复思考档位并发回跳问题、在对话流中清晰展示错误回合，并在 HTML 会话导出中脱敏编码/内嵌凭据。
- 修复 macOS `openat`/volfs 删除来源边界与构建测试隔离问题。
- 移除冗余的提示词来源与项目概览面板，精简界面与构建体积。

升级前先停止运行中的实例并备份 agent 目录，然后执行 `npm install -g @rexvane/piweb@0.3.39`。

## English

- Update the bundled Pi runtime packages (`@earendil-works/pi-*` and Chord) from **1.6.1** to **1.7.0**, syncing default model mappings and provider icons.
- Speed up cold startup with non-blocking server boot hooks, deferred update checks, background pre-warming, faster launcher readiness polling, and lazy SDK imports on hot API routes.
- Unify effective context breakdown and add the context inspector modal.
- Sync external `settings.json` and workspace resource changes in real time.
- Fix thinking-level jump-back races, surface error turns visibly in chat, and redact encoded/embedded secrets in HTML session exports.
- Pin macOS removal sources via `openat`/volfs and isolate build test mocks.
- Remove redundant prompt sources and project overview panels to streamline the UI.

Stop the running instance and back up the agent directory before upgrading with `npm install -g @rexvane/piweb@0.3.39`.
