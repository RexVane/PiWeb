# PiWeb 0.3.37

## 中文

- 修复 Windows 上已安装的 PiWeb 无法回收会话、附件及其他受支持文件的问题。回收模块从当前安装目录加载，失败时仍保留原文件。
- 修复 Windows 把旧 PiWeb 进程号分配给系统进程后，过期启动锁可能阻止启动的问题。
- 清理扩展页和说明中的旧安装提示。通过 Pi 安装的扩展仍可在扩展页管理。

## English

- Fix session, upload, and other supported Trash operations in the Windows installation. The native module loads from the installed package, and Trash failures leave the source files in place.
- Recover from stale Windows instance locks when a system process has reused the recorded PID.
- Remove references to retired install controls from Extensions and the README.
