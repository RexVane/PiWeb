# 提示词模板管理

侧栏的 **提示词模板** 位于 **扩展** 下方。这里只管理 Pi 官方的 Markdown 提示词模板，不包含 `AGENTS.md`、系统提示词文件、技能正文或工具定义；这些仍可在「提示词来源」面板查看。

PiWeb 不附带预设模板。模板来自运行用户的个人配置、受信任的项目配置或已安装的 Pi 包，更新 PiWeb 不会覆盖这些文件。

## 添加模板

个人模板放在 `<agent 目录>/prompts/`（默认 `~/.pi/agent/prompts/`），项目模板放在 `<项目>/.pi/prompts/`。项目模板需要先信任该工作区。

例如自行创建 `prompts/review.md`：

```markdown
---
description: 审阅代码改动
argument-hint: "[重点]"
---
审阅当前代码改动，重点关注 ${1:-正确性与安全性}。
```

文件名成为 `/review` 命令，`description` 和可选的 `argument-hint` 用于命令提示。参数替换由 Pi SDK 负责；PiWeb 不自行改写模板语法。默认目录只发现直接包含的 `.md` 文件；嵌套模板可以通过 `settings.json` 的 `prompts` 路径或包的 `pi.prompts` 清单声明。

也可以在 **扩展** 页安装包含模板的 npm、Git 或本地 Pi 包。安装包仍需要审查整个包的来源和内容，而不只是模板文件。

## 管理操作

- **查看**：按需读取原始 Markdown，包括 frontmatter；单文件上限 1 MiB。无法读取或解析的条目保留在列表中并显示提示。查看器保留模板来源工作区，因此切换项目后或刷新页面时不会误用当前对话的工作区读取。
- **搜索**：按名称、`/命令`、描述、路径和来源筛选。
- **作用域**：区分个人、项目和临时来源；在项目页签中选择工作区。包来源单独标记，不与作用域混为一类。
- **启停**：使用 Pi 官方的资源过滤配置。个人和项目文件写入对应 `settings.json` 的 `prompts`；包模板只修改该包的 `prompts` 过滤条件，不改 Markdown，也不影响包里的其他资源。停用条目仍在管理页中，可以重新启用。
- **删除**：只允许删除个人或项目默认模板目录中的单个文件。先预览实际路径、确认，再直接移到运行 PiWeb 的电脑的系统回收站，不另存备份或索引。文件链接只移动链接，不触碰真实目标；目录链接、包缓存和外部来源不能在这里删除。回收站不可用或移动失败时保留文件并报错，不改为永久删除。

包内模板请用单个开关停用，卸载整个包请到 **扩展** 页。外部路径的模板请在其原始来源移除，或在这里停用。

## 配置与生效

开关和 Pi 终端共用配置。例如停用个人模板时使用：

```json
{
  "prompts": ["-prompts/review.md"]
}
```

重新启用使用 `+prompts/review.md`。现有路径声明、其他模板的覆盖项、glob 过滤条件和无关设置都保留。包里的 `prompts: []` 表示全部停用；从该状态启用一个模板时不会顺带启用其余模板。

保存后 PiWeb 刷新资源和会话中的斜杠命令列表；正在执行的会话沿用现有的延后重载机制，在本轮结束后应用。刷新失败时保留已保存的配置并提示重载。单独运行的 Pi 终端需执行 `/reload` 才会读取新配置。

列表只读取本地已配置资源，不为读取清单安装缺失的包，不执行扩展工厂，也不自动发送模板内容给模型。

## 对应代码

- 界面：`src/components/workspace/PromptTemplatesWorkspaceView.tsx`、`src/components/settings/PromptTemplatesSection.tsx`
- 服务：`src/lib/prompt-templates-service.ts`；系统回收站适配：`src/lib/recycle-bin.ts`
- 接口：`/api/prompt-templates`
- 只读来源面板：`/api/prompts`；同样支持恢复已打开的停用模板，但不会因此授权读取其目录中的其他文件
