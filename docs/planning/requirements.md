## 已实现（v0.3.25，2026-10-17 定稿）

这些是用户明确表态过的界面决策，改动时按其意图走，别凭感觉调整。

- **技能怎么显示**：`/skill:name 正文` 在 pi 侧会展开成一条用户消息（SKILL.md 正文 + 正文接在 `</skill>` 之后）。界面**不**把它渲染成用户气泡，而是在本轮过程步骤里显示一行「使用技能 X」，用户打的正文挂同一行、可展开看全文。依据：Claude Code 把技能做成 `Skill(skill, args)` 工具调用（args 是入参，tool_result 只有 `Launching skill: name`），Codex 则没有技能步骤、只是读 `SKILL.md` 文件。
- **模型名不进对话区**：消息下面那一行不再显示模型名（原先出现在模型错误步骤行尾）。输入框右下角的模型按钮保留（切换模型要用）。
- **增长树**：不出现横向滚动条（滚动容器锁 `overflow-x`；行悬停的 `translateX(2px)` 会被裁在容器内）。
- **新会话页**：进入时用 pi 设置里的建议模型兜底，不再每次都要求先手动选模型；用户在工作区里显式选过的模型优先。
- **正文里的文件路径**：点开用**页内文件查看器**（不离开页面，路径不存在时查看器自己报「文件不存在」），不是本机编辑器；工具行上那个「在编辑器中打开」按钮仍然是本机编辑器。
