# `@rexvane/piweb-niubash-win32-arm64`

Windows ARM64 managed shell runtime for [PiWeb](https://github.com/RexVane/PiWeb).

This package is installed automatically as an OS/CPU-restricted optional dependency of `@rexvane/piweb`. It redistributes the complete, unmodified portable runtime from the official [niubash v1.1.4](https://github.com/unixwin/niubash/releases/tag/v1.1.4) ARM64 archive. It is not intended to be installed or invoked directly.

PiWeb uses the official Pi SDK's Bash tool with this package's `niu.exe`; it does not alter Pi's source code or the user's Pi settings. See `licenses/` for upstream license texts and `runtime-manifest.json` for source provenance and file hashes.
