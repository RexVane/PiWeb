# 设备记录补验与代次修复

日期：2026-11-14。配合 root/auth Agent 后续认证修复，业务修改仅 `src/lib/web-devices.ts` 的列表过滤；没有改认证协议、吊销持久化或插件事务。

- **非数组文件保护**：真实隔离文件分别为 `{}`、`null`、字符串。设备枚举与注册均拒绝，原内容完整保留，没有遗留临时文件或锁目录。夹具完成后进回收站。
- **最近访问缓存有界**：不暴露生产调试接口。通过内存文件/锁适配保留真实设备服务和 JSON 序列化，在一分钟内登记 1001 个不同设备；最近设备重访不重复写入，已淘汰的首个设备重访会重新进入持久记录，并更新时间。最终持久记录仍保持 200 个上限、无临时文件。该测试 177 ms，不执行千次真实跨进程文件锁。
- **时钟回拨后的新设备可见性**：带 `revocationEpoch` 的已签名设备按当前代次匹配；仅没有代次的旧记录使用 `createdAt >= notBefore`。以前两种条件同时要求，会使有效新 Cookie 在时钟落后于单调递增代次时仍不显示。回归验证真实 Cookie 签名检查通过且当前设备可见，旧代次即使时间较新也被排除，无代次记录继续按时间过滤。

最终证据 `web-devices-extra-v2-tests.json` / `.log`：**2 文件、10 passed、0 failed、0 skipped，7.60 秒**。包含 root 已有设备失败立即重试、60 秒去重、大小/持久记录上限和独立吊销回归；不得将 10 项与整仓或先前设备专项直接累加。修改后的 `npx tsc --noEmit --incremental false` 已通过。
